# Подключение из osu!
Вы можете играть на <%= brand.name %> через osu!stable.

1. Создайте ярлык для `osu!.exe`.
2. Откройте свойства ярлыка и добавьте аргумент `-devserver` в конец поля **Объект**:

```
C:\Users\user\AppData\Local\osu!\osu!.exe -devserver <%= (brand.url:gsub("^https?://", "")) %>
```

Замените путь на актуальный, если игра установлена в другом месте.

3. [Войдите на сайте](/login) хотя бы один раз. Это создаст ваш аккаунт.
4. Запустите osu! через новый ярлык и войдите в аккаунт <%= brand.name %>.

Всегда запускайте игру через этот ярлык, чтобы играть на <%= brand.name %>. Обычный запуск osu! подключает к официальным серверам.
