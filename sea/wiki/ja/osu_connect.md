# osu! から接続する
osu!stable を使って <%= brand.name %> をプレイできます。

1. `osu!.exe` のショートカットを作成します。
2. ショートカットのプロパティを開き、**リンク先** の末尾に `-devserver` 引数を追加します:

```
C:\Users\user\AppData\Local\osu!\osu!.exe -devserver <%= (brand.url:gsub("^https?://", "")) %>
```

ゲームを別の場所にインストールしている場合は、パスを実際の場所に置き換えてください。

3. [ウェブサイトにログイン](/login) します(最低1回)。これでアカウントが作成されます。
4. 新しいショートカットから osu! を起動し、<%= brand.name %> のアカウントでログインします。

<%= brand.name %> をプレイするときは、必ずこのショートカットを使用してください。通常の起動では公式サーバーに接続されます。
